### What is a Container?

A container is a standardized unit that packages up your code and all of its dependencies. This package is designed to run reliably on any platform, because the container creates its own independent environment.

- AWS has container management services such as ECS (Elastic Container Service) and EKS (Elastic Kubernetes Service)

### AWS Lambda

AWS Lambda is a serverless compute service that runs your code in response to events. You upload your function (or container image), and AWS handles the servers, scaling, and patching. You pay only for the compute time your code actually uses, measured in milliseconds.

- No servers to provision or manage
- Automatically scales up or down with the number of incoming requests
- Supports many languages (Python, Node.js, Java, Go, .NET, Ruby, and custom runtimes)
- Default timeout is 3 seconds; maximum is 15 minutes
- Functions run inside a VPC when needed to access private resources (RDS, ElastiCache, etc.)
